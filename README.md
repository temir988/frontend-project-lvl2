# frontend-project-lvl2

[![Lint and tests](https://github.com/temir988/frontend-project-lvl2/actions/workflows/nodejs.yml/badge.svg)](https://github.com/temir988/frontend-project-lvl2/actions/workflows/nodejs.yml)

To install dependencies:

```bash
npm install
```

To run:

```bash
node src/cli.ts
```

Usage:

```bash
node src/cli.ts <filepath1> <filepath2>
```
